# كريب حكاية — Crepe Hekaya 🥞

المنيو الرقمي الرسمي والتفاعلي لمطعم **كريب حكاية — Crepe Hekaya**.

## ✨ مميزات المشروع
- **تصميم عصري وفاخر (Ultra-Luxury Dark Theme)** متوافق مع الهوية البصرية للمطعم.
- **عرض سريع وخفيف للأصناف (Zero-Latency)** بدون أي أطر عمل معقدة، متوافق 100% مع جميع الهواتف الذكية.
- **مفتاح تبديل الجبن (Cheese Variant Switcher):** تصفح الأسعار الفورية (سادة / رومي / موزاريلا) بضغطة زر.
- **بحث فوري وفلترة بالأقسام:** لسهولة وسرعة الوصول للأصناف والمكونات.
- **مشغل فيديو واستعراض حركي للأصناف.**
- **جاهز للنشر المباشر عبر Vercel.**

## 🚀 التشغيل والنشر
المشروع مبني بـ HTML5 / CSS3 / Vanilla JavaScript، ولا يحتاج لأي خطوات بناء (Build steps).
يمكن ربط المستودع مباشرة بـ **Vercel** واختيار:
- **Framework Preset:** `Other`
- **Root Directory:** `./`
وسيتم النشر والتشغيل فوراً!
